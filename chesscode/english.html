North = up · South = down · East = right · West = left. Squares are labelled a–h and 1–8.

How to play and what you will learn

This game follows the idea behind Compute It: read a program, mentally trace its execution, and predict the result. The chess piece acts as a coding cursor: normal chess movement rules do not apply. Commands N, S, E, W and diagonals move the cursor one square. If it tries to leave the board, it stays in place.

if lightSquare(): check the current square before choosing; a1 is dark. if onEdge(): the piece is on rank 1 or 8, or file a or h. if evenFile(): check the file number (a=1, b=2...). repeat: run the whole block several times. function: reuse a group of instructions.

Levels 1–6 teach sequences; 7–12, loops; 13–18, conditions; 19–24, nested loops; and 25–30, functions and combined algorithms. Progress is stored only in this browser.
