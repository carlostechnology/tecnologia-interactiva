# Tecnología Interactiva

### Interactive STEM Learning Resources

**Recursos educativos interactivos para aprender Tecnología, Electrónica y Programación.**

Este repositorio reúne actividades y proyectos para estudiantes de Educación Secundaria, especialmente de **Tecnología y Digitalización**, con materiales adaptados a la enseñanza bilingüe (CLIL).

Los recursos combinan explicaciones sencillas, simulaciones, experimentación y retos prácticos.

| Proyecto | Descripción | Estado |

## Arduino from Zero

**From a blinking LED to a chess clock**

Un laboratorio interactivo para alumnado de 3.º ESO bilingüe.

Incluye:

- Diez prácticas progresivas con Arduino UNO R4 WiFi.
- Programas de Arduino listos para utilizar.
- Simuladores interactivos.
- Vocabulario técnico inglés-español.
- Preguntas y actividades CLIL.
- Retos y ejercicios de autoevaluación.
- Un proyecto final: un reloj de ajedrez digital.

## Nuestra metodología

**Learn → Build → Test → Improve**

Aprender haciendo, experimentar, observar resultados y mejorar los diseños.

Los materiales buscan desarrollar el pensamiento computacional, la creatividad y la resolución de problemas tecnológicos.
