# Tecnología Interactiva

### Interactive STEM Learning Resources

**Recursos educativos interactivos para aprender Tecnología, Electrónica y Programación.**

Este repositorio reúne actividades y proyectos para estudiantes de Educación Secundaria, especialmente de **Tecnología y Digitalización**, con materiales adaptados a la enseñanza bilingüe (CLIL).

Los recursos combinan explicaciones sencillas, simulaciones, experimentación y retos prácticos.

## Arduino from Zero

**From a blinking LED to a chess clock**

Un laboratorio interactivo para alumnado de 3.º ESO bilingüe.

Incluye:

- Diez prácticas progresivas con Arduino UNO R4 WiFi.
- Programas de Arduino listos para utilizar.
- Simuladores interactivos.
- Vocabulario técnico inglés-español.
- Preguntas y actividades CLIL.
- Retos y ejercicios de autoevaluación.
- Un proyecto final: un reloj de ajedrez digital.


## Hexapawn Lab

**From a simple chess game to Artificial Intelligence**

Laboratorio interactivo para estudiantes de 2.º de Bachillerato, integrado en el proyecto SmartChess.

A partir de un tablero de ajedrez de 3 × 3, los estudiantes descubren cómo representar problemas, diseñar algoritmos y construir sistemas capaces de tomar decisiones.

### ¿Qué incluye?

- Juego de Hexapawn completamente interactivo.
- Tres adversarios: aleatorio, minimax y aprendizaje por refuerzo elemental.
- Modo para dos jugadores.
- Desafíos de lógica y estrategia.
- Introducción progresiva a la programación en Python.
- Representación de tableros mediante listas y matrices.
- Laboratorio de inteligencia artificial y análisis de decisiones.
- Experimentos sobre aprendizaje automático.

### Objetivos educativos

- Desarrollar el pensamiento computacional.
- Comprender los algoritmos de búsqueda y decisión.
- Introducir el algoritmo minimax.
- Explorar conceptos básicos del aprendizaje por refuerzo.
- Aplicar el método científico a la evaluación de algoritmos.

## Nuestra metodología

**Learn → Build → Test → Improve**

Aprender haciendo, experimentar, observar resultados y mejorar los diseños.

Los materiales buscan desarrollar el pensamiento computacional, la creatividad y la resolución de problemas tecnológicos.
